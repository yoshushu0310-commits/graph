# 📚 공부 습관 대시보드 (Study Habit Dashboard)

> 파이썬의 **Pandas**와 **Streamlit**을 활용하여 학생들의 공부 시간, 스마트폰 사용 시간, 성적 간의 관계를 한눈에 파악할 수 있는 인터랙티브 웹 대시보드입니다.

---

## 📌 주요 기능 (Features)

* **핵심 지표 요약 (`st.metric`)**
  * 전체 학생 수, 평균 성적, 평균 공부시간을 한눈에 확인할 수 있는 요약 카드 제공

* **조건별 데이터 필터링 (`st.slider`)**
  * 슬라이더를 조절하여 원하는 '최소 공부시간' 이상인 학생 데이터만 동적으로 조회

* **시각화 차트 (`st.chart`)**
  * **공부시간 vs 점수 (산점도)**: 공부시간과 성적 간의 연관성 파악
  * **학생별 점수 비교 (막대 그래프)**: 필터링된 학생들의 점수를 직관적으로 비교

* **상세 데이터 조회 (`st.expander`)**
  * 조건에 맞게 필터링된 원본 데이터 테이블을 접기/펴기 형태로 제공

---

## 🛠️ 기술 스택 (Tech Stack)

* **언어**: Python 3.x
* **데이터 분석**: Pandas
* **웹 프레임워크**: Streamlit
